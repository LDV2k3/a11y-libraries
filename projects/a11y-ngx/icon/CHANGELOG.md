# Changelog

## v2.0.0 - 2026-11-15

### 🔧 Changed

- Updated Angular peer dependency range to `v14.2.0` - `v22.x`.

### 🐛 Fixed

- Fixed the case where changing `label` dynamically caused the icon to be removed.
- Fixed the default icon size to `1em` instead of `1rem`.

## v1.0.1 - 2026-07-16

### 🐛 Fixed

- Fixed the case when `icon` changes from an active icon to `undefined`.

## v1.0.0 - 2026-05-13

### 🚀 Added
