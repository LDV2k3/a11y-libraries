# Changelog

## v2.0.0 - 2026-11-13

### 🚀 Added

- Added `theme` setter to manually update the current theme.
- Added `.a11y-caret` (pointing right by default), along with direction modifiers `.a11y-caret-down`, `.a11y-caret-up` or `.a11y-caret-left`.

### 🔧 Changed

- Upgraded Angular peer dependency to `>=14.2.0`.

### 🐛 Fixed

- Fixed the `--a11y-text-color-dark` token.
- Fixed the `--a11y-disabled-text-color` tokens.
- Fixed the `--a11y-focus-visible-shadow` tokens.
- Fixed `provideA11yTheme()` not enforcing a required value.

## v1.0.4 - 2026-07-16

### 🚀 Added

- Initial release of the library.
